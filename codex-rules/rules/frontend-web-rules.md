# 网站前端规范

## 产品定位

AxialMuseWebsite 前端默认服务于阅读、项目理解和后续产品服务探索。界面应克制、清晰、可信，不用复杂装饰替代内容层次。

## 交互设计

- 第一屏必须让访问者理解 Axial Muse 是什么。
- 导航应稳定、短、可扫描。
- 技术文章、项目和产品服务入口需要区分层级。
- 用户可见文案默认简体中文。
- 不使用会遮挡正文或降低阅读效率的动效。

## 技术规则

- 优先沿用项目既有技术栈；当前首版为零依赖静态页面。
- 引入框架、组件库、图标库、分析脚本或第三方服务前，先更新设计文档。
- 资源路径、内部链接和站点入口必须能被质量脚本检查。
- 错误状态、空状态、加载状态和权限不足状态在未来交互页面中必须可见。

## 验证

前端改动后必须实际运行页面并做渲染或截图验证。检查：

- 文本不重叠、不溢出。
- 移动端和桌面端关键视图可用。
- 导航、锚点、按钮和链接可访问。
- 没有暴露隐私、密钥或未确认产品承诺。
