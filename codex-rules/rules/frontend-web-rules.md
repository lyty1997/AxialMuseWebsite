# 网站前端规则

前端实现以[主站编码规范 Spec](../../docs/engineering/main-site-coding-spec.md)为实现入口，并追溯[主站体验与内容架构](../../docs/product/site-experience.md)和[主站目标架构](../../docs/architecture/main-site-target-architecture.md)；不得从旧页面反推设计，也不得在本文件复制当前技术栈。

## 体验

- 第一屏说明 Axial Muse 是什么；导航短、稳定、可扫描，文章、项目和产品入口层级清晰。
- 界面优先服务阅读和项目理解，不用装饰或遮挡正文的动效替代内容层次。
- 响应式、可访问性、状态和视觉要求服从已确认设计；错误、空、加载和权限不足状态不得被静默隐藏。

## 实现边界

- 框架选型只授权设计文档明确的基线；具体版本、preset、插件拓扑、主题覆盖、额外依赖、自定义客户端能力和第三方服务仍须分别确认。
- 依赖许可与准入按[主站目标架构](../../docs/architecture/main-site-target-architecture.md)执行；宽松许可证不等于具体包、版本、传递依赖、浏览器请求或数据处理已获授权。
- 资源路径、内部链接和站点入口必须可由质量门禁检查。

## 验证

前端改动必须实际渲染或截图，覆盖关键桌面端与移动端视图，并检查文本重叠或溢出、导航与交互可访问性、资源和链接，以及隐私或未确认产品承诺泄露。
