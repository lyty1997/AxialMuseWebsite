# 安全与隐私规范

## 密钥与凭证

- 不提交 API Key、Secret、token、密码、私钥、cookie、session、真实服务凭证。
- `.env` 和 `.env.*` 默认不进入版本库；示例配置使用 `.env.example`。
- 质量门禁会扫描常见密钥形态，但不能替代人工审查。

## 个人与用户数据

- 不公开真实个人隐私、客户信息、未授权截图、内部沟通记录或未公开商业计划。
- 引入表单、评论、订阅、登录、分析或第三方脚本前，必须先记录数据收集字段、用途、存储位置和删除方式。

## 外部内容

- 引用外部资料时保留来源链接。
- 不复制大段受版权保护内容。
- 对观点和事实做区分，避免把引用材料改写成本站原创结论。
