# 安全与隐私规则

## 凭证

- 不提交、打印或写入 API Key、Secret、token、密码、私钥、cookie、session 或真实服务凭证。
- 本地环境文件必须被 Git 忽略；示例配置只保留占位值。自动密钥扫描不能替代人工审查。

## 个人与用户数据

- 不公开真实个人隐私、客户信息、未授权截图、内部沟通或未公开商业计划。
- 引入表单、评论、订阅、登录、分析或第三方脚本前，先确认字段、用途、存储位置、保留周期、删除与导出、反滥用和第三方依赖。
- 浏览器自动请求第三方或境外 origin 前，单独确认发送字段、接收方、处理地域、法律与同意基础、保留和退出方式；开源许可证不替代数据与隐私评审。

## 外部内容

- 保留来源和授权依据，不复制大段受版权保护内容，不把他人观点或材料包装为本站原创结论。
