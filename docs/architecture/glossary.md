# 术语表

状态：active  
最近更新：2026-07-13

## 核心术语

- Axial Muse：个人项目、技术分享和未来产品服务的公开网站品牌。
- 技术分享：围绕个人项目的设计、实现、复盘、工具链和工程规范文章。
- 产品服务：后续可能面向用户提供的工具、咨询、自动化能力或内容服务。
- 讨论入口：未来可能引入的评论、反馈、社区或异步讨论机制。
- 真相源：定义项目事实的文档或配置。当前 `docs/` 是定位、架构和内容模型的真相源。
- 契约词表：跨文档、代码、页面共享的稳定命名集合，位于 `docs/contracts/contract-terms.json`。
- canonical URL：同一内容存在多个可访问地址时，指定给访问者和搜索引擎的首选正式地址。
- 生产部署：由 `main` 分支触发、通过正式域名对外提供的版本。
- 预览部署：由非生产分支生成、用于合并前验收且不应进入搜索索引的版本。
- 权威 DNS：对域名记录给出正式答案的 DNS 服务；首版计划使用腾讯云 DNSPod。
- DNSSEC：为 DNS 响应建立签名验证链，降低解析结果被伪造的风险。
- Lighthouse：腾讯云轻量应用服务器，本项目首版生产静态站点的计算资源。
- TAT：TencentCloud Automation Tools，腾讯云原生远程运维工具，本项目用于触发受限生产发布。
- CAM：Cloud Access Management，腾讯云权限控制系统，用于限制 GitHub 部署凭证可执行的云操作。
- ACME：自动签发和续期 TLS 证书的标准协议。
- RTO：故障发生后恢复服务所允许的目标时间。
- RPO：故障恢复时可接受的数据回退点。
- 项目体验：可直接操作或查看项目实际效果的独立公开站点，使用 `<project-slug>.axialmuse.com`。
- 项目体验注册表：记录项目子域名、状态、发布模式、健康检查和数据边界的机器可读真相源。
- host-only Cookie：未设置 `Domain` 属性、只发送给创建它的精确主机名的 Cookie；用于隔离不同项目子域名。

## 表达规则

- 已上线能力：可以用确定语气描述。
- 计划能力：使用“计划”“探索”“后续可能”等表达。
- 待确认事项：写入 `docs/architecture/open-decisions.md`。
